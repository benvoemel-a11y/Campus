# Campus

Lern-App: Lernzeit eintragen, Lernzettel und Karteikarten pro Fach, Lernkalender, Prüfungsmodus.

Läuft komplett im Browser. Die Daten bleiben auf dem Gerät (localStorage) und werden **nicht** in dieses Repository geschrieben.
Backups: in der App unter **Zeiten → Daten und Backup**.

Als App auf dem iPhone: Seite in Safari öffnen → Teilen → „Zum Home-Bildschirm“.
Auf dem Mac: Safari → Ablage → „Zum Dock hinzufügen“.
